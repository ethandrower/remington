Can't find this user via search? How to get their ID manually
  1. Go to home.atlassian.com
  2. Click Teams in the left sidebar, then People
  3. Search for the person and click their name
  4. Grab the ID from the browser URL bar:
    home.atlassian.com/…/people/<account-id>?cloudId=…
    — everything between /people/ and ? is the Account ID
  5. Paste it into the Jira Account ID field above

This is needed when a user's Jira profile is set to private — automated search won't find them, but their ID is always visible in the URL.

Auto-Reconcile Team Members

How it works

  1. Fetches all Jira assignees from your project's recent tickets
  2. Fetches all active Slack workspace members
  3. Asks Claude to match people across both platforms by name and email
  4. You review and accept each suggestion before anything is saved

Already-mapped users are excluded automatically.

Prerequisites: the following env vars must be set in your .env: JIRA_INSTANCE_URL, ATLASSIAN_SERVICE_ACCOUNT_EMAIL, ATLASSIAN_SERVICE_ACCOUNT_TOKEN, ATLASSIAN_PROJECT_KEY, SLACK_BOT_TOKEN, ANTHROPIC_API_KEY.
If not all are set, the fetch step will report errors and still show whatever it could retrieve.
